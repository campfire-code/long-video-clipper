长视频一键切爆点

把一个视频链接或本地长视频，自动切成多条适合抖音、小红书、TikTok、YouTube Shorts、B 站的短视频，并生成封面和发布文案。

怎么用

  1. 安装并打开：Mac 把应用拖进「应用程序」后右键 → 打开；Windows 运行安装包
  2. 打开「设置」，选分析模型服务商，填自己的 API Key 和模型名，测试连接后保存
  3. 在首页用「文件导入」选视频（可附 .srt）或「链接导入」粘贴链接，选目标平台
  4. 预览自动生成的片段，检查起止、字幕和标题后导出
交付形式　桌面安装包（Mac Apple 芯片 .dmg / Windows 64 位 .exe），剪辑与渲染在自己电脑上完成
